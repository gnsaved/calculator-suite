# Unit Converter

A clean browser-based converter focused on common units.

## Features
- Length conversions (e.g., m, cm, km, inches, feet)
- Mass conversions (e.g., kg, g, lb)
- Time conversions (e.g., seconds, minutes, hours, days)
- Simple, fast UI

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
Open `index.html` in your browser.
