# Body Fat Calculator (US Navy Method)

A body fat percentage estimator using the **US Navy formula** and optional lean/fat mass outputs.

## Features
- US Navy body fat % estimation
- Lean mass + fat mass breakdown (if included)
- Male/Female inputs (hip measurement for female if your version supports it)

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
Open `index.html` in your browser.

## Note
Results are estimates and should not be treated as medical advice.
