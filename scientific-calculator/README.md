# Scientific Calculator

A feature-rich browser-based scientific calculator built using **Vanilla JavaScript** with a clean UI and fast keyboard-friendly flow.

## Files
- `index.html` — Main scientific calculator version
- `pro.html` — Enhanced/alternate UI version
- `legacy.html` — Earlier version kept for iteration history

## Features
- Standard operations: `+ - × ÷`
- Trigonometry: `sin`, `cos`, `tan`
- Logarithms: `log`, `ln`
- Angle modes: `RAD` / `DEG` (if implemented in your version)
- Memory keys (if included): `MC`, `MR`, `M+`, `M-`
- History panel / reuse (if included)

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
Open `index.html` in your browser, or host the folder on any static hosting.
