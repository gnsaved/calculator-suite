# BMI & Weight Calculator

A simple health tool that calculates **Body Mass Index (BMI)** from height and weight and provides basic guidance such as healthy BMI range and target weight (where applicable).

## Features
- BMI calculation from user input
- Healthy BMI range reference
- Target/ideal weight estimation (if implemented)
- Supports common units (cm/m, kg/lb) depending on your UI

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
Open `index.html` in your browser.
