# Data Size + Bandwidth Converter

A data utility that converts between data units and estimates download time based on connection speed.

## Features
- Convert bits/bytes and common units (KB/MB/GB/TB)
- Base-10 vs Base-2 conversion support (if implemented)
- Download time estimator from file size and speed

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
Open `index.html` in your browser.
