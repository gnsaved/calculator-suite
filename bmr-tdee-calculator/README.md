# BMR & TDEE Planner

A calorie planning calculator that estimates:
- **BMR (Basal Metabolic Rate)**
- **TDEE (Total Daily Energy Expenditure)**
- Calorie targets for **maintenance, cutting, or bulking**
- Macro suggestions (if included)

## Features
- BMR calculation (e.g., Mifflin-St Jeor if that’s what you implemented)
- Activity multiplier to estimate TDEE
- Calorie goal planning (lose/gain/maintain)
- Macro breakdown guidance (optional)

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
Open `index.html` in your browser.
